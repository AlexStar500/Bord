# Bord

Текстовый редактор для GitHub Pages: профили, несколько документов, офлайн-кэш (PWA), языки EN / RU / PL.

## Запуск на GitHub Pages
1. Создайте репозиторий и загрузите в корень все файлы: `index.html`, `sw.js`, `manifest.webmanifest`, `icon.svg`.
2. Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)`.
3. Через минуту сайт откроется по адресу `https://<ваш-ник>.github.io/<репозиторий>/`.

## Важно
- GitHub Pages — статический хостинг, сервера нет. Профили и документы хранятся в `localStorage` браузера на конкретном устройстве и не синхронизируются между устройствами. Пароль профиля — только локальная блокировка, а не настоящая защита данных.
- Кэш: Service Worker отдаёт сайт мгновенно и без интернета, а в фоне обновляет его. При изменении файлов поменяйте `V='bord-v1'` в `sw.js` на `bord-v2` и т. д.
- Язык определяется по браузеру и переключается в верхней панели.
